# Failure Modes and Mitigations (FAILURE_MODES.md)

This document catalogs every potential failure mode in the `bodhan_dub` pipeline, detailing how each is detected, mitigated, and verified with automated tests.

---

## Failure Mode Matrix

| ID | Stage | Failure Mode | Root Cause | Detection Mechanism | Mitigation Strategy | Test Reference |
|---|---|---|---|---|---|---|
| **FM-001** | Ingest / Preflight | Corrupt or invalid media file | Incompatible container, truncated download, or missing headers | `ffprobe` stream inspection exits with non-zero code | Abort immediately with exit code 2; print clear error message | `tests/unit/test_preflight.py::test_validate_duration_bounds` |
| **FM-002** | Ingest / Preflight | Missing audio or video stream | Video-only or audio-only source provided | Stream count check in `validate_media_file` | Raise `PreflightError` and exit 2 with clear explanation | `tests/unit/test_preflight.py` |
| **FM-003** | Ingest / Preflight | Duration outside bounds (<1 min or >15 min) | Extreme input duration provided | Total duration check in `validate_duration` | Warn if slightly outside (10s–60s); reject absurd inputs (<10s or >30m) with exit code 2 | `tests/unit/test_preflight.py::test_validate_duration_bounds` |
| **FM-004** | VAD | Silent or music-only video | No spoken dialogue in video | VAD speech duration = 0.0s (`has_speech = False`) | Set status `ok_no_speech`, copy input video, output empty transcript/subtitles, exit 0 | `tests/unit/test_edge_cases.py::test_silent_video_passthrough` |
| **FM-005** | VAD | ONNX runtime failure or missing weights | Platform dependency or memory constraints | `try-except` on Silero ONNX initialization | Automatically fall back to ffmpeg `silencedetect` without interruption | `tests/unit/test_vad.py::test_silero_fallback` |
| **FM-006** | Chunking | ASR audio exceeding 30s ceiling | Monologue with no pauses for >30 seconds | Hard chunk duration check (`>29.0s`) | Cut at lowest RMS energy frame with 1.5s overlap and deduplicate | `tests/unit/test_chunks.py::test_chunk_planner_hard_max_ceiling` |
| **FM-007** | ASR | Empty response while VAD sees speech | FastConformer acoustic dropout or noise mask | Response text empty while chunk has speech regions | Retry chunk, then split chunk in half and retry (max 2 attempts) | `tests/unit/test_fake_bodhan.py::test_fake_bodhan_transcribe` |
| **FM-008** | ASR | Hallucination or looping on music/silence | Model autoregressive looping or phantom tokens | `<40%` VAD overlap (`no_speech_overlap`) or repeated n-grams (`asr_loop`) | Discard hallucinated segment; log reason in JSONL | `tests/unit/test_segmenter.py` |
| **FM-009** | Segmenter | Run-on sentence exceeding TTS capacity | Unbroken sentence lasting >12 seconds | Clause duration check (`duration > 12.0s`) | Split at subordinating conjunctions and punctuation into safe sub-slots | `tests/unit/test_segmenter.py::test_deterministic_split_long_sentences` |
| **FM-010** | Segmenter | LLM invalid JSON or modified transcript | Non-deterministic LLM hallucination | Pydantic JSON schema check and exact text preservation check | Fall back to deterministic sentence segmentation | `tests/unit/test_segmenter.py::test_deterministic_merge_fragments` |
| **FM-011** | Glossary | Named entity / technical term distortion | Indic-Translate altering brand names or acronyms | Exact token matching against transcript and glossary | Protect with `__TERM_{i}__` tokens before translate; restore post-translation | `tests/unit/test_spans.py::test_protect_terms_priority_and_boundaries` |
| **FM-012** | Glossary | Numerical discrepancy in translation | Model hallucinating numbers or dropping quantities | `extract_numbers` Indic and ASCII comparison | Reject translation; retry with LLM English paraphrase | `tests/unit/test_spans.py::test_verify_numbers_preserved` |
| **FM-013** | Translation | Dominant script mismatch | Indic-Translate generating Latin characters or incorrect script | `check_dominant_script` Unicode block comparison | Reject translation; retry up to 4-step ladder | `tests/unit/test_translate.py::test_check_dominant_script` |
| **FM-014** | Translation | Back-translation semantic drift | Subtle mistranslation or critical omissions | English-only LLM judge compares source and back-translation | Flag `mistranslation` or `omission`; trigger LLM English paraphrase | `tests/unit/test_translate.py::test_translation_stage_with_fake_bodhan` |
| **FM-015** | TTS | Audio truncation on long text | Indic-Speak server truncates audio at ~30.55s | Text length check (`>180 chars`) | Split text at clause punctuation into ≤180 char pieces; stitch with 10ms crossfades | `tests/unit/test_tts.py::test_split_text_at_punctuation_long_text` |
| **FM-016** | TTS / QA | High CER on synthesized speech | Mispronunciation or phonetic blur | Back-transcription CER check (`CER ≥ 0.30`) | Bounded retry ladder (re-synthesize, split text, paraphrase, condense) | `tests/unit/test_qa.py::test_speech_qa_evaluate_passing` |
| **FM-017** | TTS / QA | Tail omission / truncation by TTS | Model dropping end of sentence | Normalized tail token comparison (`detect_tail_omission`) | Retry with sentence split at previous comma or punctuation | `tests/unit/test_cer.py::test_tail_omission_detection` |
| **FM-018** | TTS / QA | Audio clipping or internal silence | Model gain overshoot or sudden acoustic dropout | Peak sample amplitude check (`max ≥ 0.999`) and internal silence detector | Mark QA fail; re-synthesize or re-plan | `tests/unit/test_qa.py::test_speech_qa_evaluate_clipped_and_silent` |
| **FM-019** | Fit | Syllable expansion causing duration overrun | Target Indic language takes significantly longer to speak | Predicted or actual duration exceeds slot duration | Borrow slack (up to 250ms before + trailing slack); cap stretch strictly at 1.20x; flag overrun | `tests/unit/test_fit.py::test_fit_controller_borrow_slack` |
| **FM-020** | Fit | Excessive time-stretch chipmunk effect | Attempting to fit massive text by speeding up | Speed factor clamp (`speed_factor ≤ 1.20`) | Never exceed 1.20x stretch; borrow slack or flag overrun | `tests/unit/test_fit.py::test_fit_controller_overrun_capped_at_1_20` |
| **FM-021** | Schedule | Segment collision on timeline | Consecutive segments overlapping due to duration stretch | `placed_start < last_placed_end` check | Enforce `placed_start = max(target_start, last_placed_end)` | `tests/unit/test_schedule.py::test_timeline_scheduler_placement` |
| **FM-022** | Mix | Dialogue bleed and background music loss | Abrupt speech removal or music ducking | Fixed-width linear fade envelope (40ms) | Smoothly duck speech regions while preserving un-muted audio for skipped slots | `tests/unit/test_loudness_mix.py::test_mute_intervals_with_crossfade` |
| **FM-023** | Mix | Audio clipping or non-compliant loudness | Summing background and speech stems | BS.1770 integrated LUFS measurement and true-peak detector | Normalize to -16.0 LUFS integrated (±1.0 LUFS) with -1.0 dBTP peak limiter | `tests/unit/test_loudness_mix.py::test_loudness_normalization_and_peak_limiting` |
| **FM-024** | Mux | Video/audio duration desync | Container timestamps differing between audio and video | ffprobe post-mux duration check (`abs(v_dur - a_dur) > 100ms`) | Bounded repair: pad/trim audio WAV to exact video samples, re-mux (max 2 attempts) | `tests/unit/test_mux.py::test_mux_and_verify` |
| **FM-025** | Gateway | 429 Rate Limit Exceeded | API quota or bursts | HTTP 429 response status | Exponential backoff with jitter, honoring `Retry-After` header | `tests/unit/test_fake_bodhan.py::test_fake_bodhan_fault_injection` |
| **FM-026** | Gateway | 5xx Server Outage | Bodhan or LLM infrastructure failure | HTTP 5xx responses (500, 502, 503, 504) | Circuit breaker opens after 5 consecutive failures; fails language fast while other languages continue | `tests/unit/test_edge_cases.py::test_circuit_breaker` |
| **FM-027** | Gateway | Budget exhaustion | High processing volume or token usage | `BudgetGuard.check_budget` before every paid API call | Halt cleanly, write partial outputs, report.json, manifest, and exit | `tests/unit/test_edge_cases.py::test_budget_guard_exceeded` |
| **FM-028** | Security | Prompt injection in transcript | Malicious user video containing prompt injection commands | Strict prompt wrapping and Unicode range rejection | LLM input/output strictly guarded; non-English characters rejected | `tests/unit/test_edge_cases.py::test_prompt_injection_and_policy_guards` |
| **FM-029** | Fit | Syllable expansion causing >1.20 duration overflow | Target Indic language requires excessive speech duration | Post-synthesis ratio check (`raw_dur / slot_duration > 1.20`) | Execute 2-pass LLM English condensation with entity preservation guard; re-translate and re-synthesize | `tests/unit/test_fit.py::test_fit_post_synthesis_condense_success` |
| **FM-030** | Schedule | Cascading timeline desync from earlier overrun | Cumulative delay pushing subsequent segments out of lip sync | Lookahead boundary check in `TimelineScheduler` | Subsequent segments start at their own source start; borrow slack and cap stretch at 1.20x; flag local overrun without cascade | `tests/unit/test_schedule.py::test_schedule_non_cascading_overrun` |
| **FM-031** | Mix | Intersample peak distortion upon AAC conversion | Signal reconstruction producing peaks exceeding 0 dBFS | 4x polyphase true-peak measurement via `scipy.signal.resample_poly` | Apply true-peak limiting with -1.0 dBTP ceiling before muxing | `tests/unit/test_loudness_mix.py::test_true_peak_limiter_polyphase` |
| **FM-032** | Subtitles | Phantom or desynced cues on skipped segments | Subtitle engine emitting cues for untranslated or skipped slots | Slot status check in subtitle generator | Suppress subtitle cue generation for skipped or `translation_failed` slots; use placed timestamps | `tests/unit/test_subtitles.py::test_target_subtitles_omits_skipped_and_matches_placed_count` |
| **FM-033** | Gateway | Cross-language circuit breaker cascade | Single language outage tripping breakers for other languages | Isolated `CircuitBreakerRegistry` per `(service, language)` | Outage in one language (e.g. Tamil speak) trips only its own breaker; others proceed | `tests/unit/test_resilience.py::test_circuit_breaker_isolation_tamil_speak_tripped_hindi_transcribe_works` |
| **FM-034** | Gateway | Semaphore starvation during 429 rate limit backoff | Holding semaphore while sleeping on 429 starves concurrent tasks | Scoping `async with semaphore` strictly around network call | Releases semaphore before `asyncio.sleep` so concurrent tasks proceed during backoff | `tests/unit/test_resilience.py::test_semaphore_not_held_during_429_backoff` |
| **FM-035** | Security / LLM | Prompt injection in transcript hijacking LLM commands | Malicious transcript containing instructions | Wrapping text in `<data>...</data>` with explicit passive instructions; `HostAllowlistGuard` | Treats text purely as passive data; rejects unauthorized hosts | `tests/unit/test_llm.py::test_llm_prompt_injection_isolation` |
| **FM-036** | VAD | Corrupted or poisoned local Silero VAD model | Incomplete or altered `silero_vad.onnx` asset | Cryptographic SHA256 integrity verification against pinned hash | Logs warning and falls back cleanly to ffmpeg `silencedetect` without crash | `tests/unit/test_vad.py::test_silero_vad_corrupt_weights_fails_hash_check_and_falls_back` |
| **FM-037** | CLI / Pipeline | Pipeline failure or interruption without checkpointing | Premature kill (SIGINT) or unhandled error | Async signal handling, partial report writing, and `--resume` support | Skips completed segments and reuses cached intermediate WAVs | `tests/unit/test_cli_flags.py::test_flag_resume_skips_completed_segments` |
